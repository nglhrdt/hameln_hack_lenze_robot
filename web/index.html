API- und Stream-Schnittstelle / vorläufiges Format

Richtungstaste „Hoch“ bei Start (50 / 50) und 5-%-Schritt: {"inputType":"text","data":"Fahre nach oben. Zielposition: X=50 %, Y=55 % (jeweils 0 bis 100 Prozent)."}. Es werden keine Millimeter gesendet.

Command-API: POST {protocol}//{host}/command mit {"inputType":"text","data":"Dein Befehl"}. Übertragen werden endgültige Sprachsegmente, manuell gesendete Texte und die Befehle der Richtungstasten. Browser-Events behalten das unten gezeigte Stream-Format. Requests werden nacheinander verarbeitet.

Bei Netzwerkfehlern wird die API-Weiterleitung pausiert. Nicht bestätigte Nachrichten werden nicht automatisch wiederholt. Die API muss eine erfolgreiche Verarbeitung mit einem 2xx-Status bestätigen. Ein optionales Telemetrie-JSON in der Antwort aktualisiert den Phantomschlitten.

Im Browser: window.addEventListener("transcript:update", event => console.log(event.detail))

Ein Segment behält seine ID während der Überarbeitung. text ersetzt den bisherigen Segmenttext. isFinal markiert den Abschluss. fullText ist der aktuelle Gesamttext. Zwischenstände nicht einfach aneinanderhängen. 

{"type":"transcript","sessionId":"…","segmentId":"…:0","sequence":1,
 "text":"Bewege den Arm","isFinal":false,"fullText":"Bewege den Arm",
 "language":"de-DE","timestamp":"…"}

Abschluss einer Aufnahme: {"type":"transcript.end","sessionId":"…","sequence":2,"reason":"stopped"} . Abbruch oder Fehler schließt vorläufige Segmente nicht als endgültig ab. Nicht verbundene Nachrichten werden nicht nachträglich gesendet.

Lokales Ziel-Event (zusätzlich zum API-Request): {"type":"target","position":{"x":50,"y":55},"units":"percent"}

Ist-Position empfangen: {"type":"telemetry","position":{"x":48,"y":52},"units":"percent"} . Ohne WebSocket kann ein Adapter dieselben Daten über window.motionInterface.updateTelemetry(message) einspielen.

API-Anfragen und Antworten stehen im Logfenster der Steuerungsansicht. Bei HTTPS-Seiten ist die HTTP-API durch Mixed Content blockiert; localhost oder einen HTTPS-Proxy verwenden.
